# 整理材料

適用於使用者提供零散想法、筆記或資料，想整理成可分析的材料。先辨識這批材料要支援的問題或決策。若目標未知但仍能整理，先按原文主題交付，並標出分組依據。

| 想取得的結果 | 做法 | 輸出 |
| --- | --- | --- |
| 把腦中零散想法理出頭緒 | 按主題歸類，區分觀察、想法、限制與疑問，保留互相衝突的內容 | 主題、每組要點、未解問題。若使用者希望繼續推進，再給一個下一步 |
| 將資訊整理成框架 | 依用途選大綱、對照表或層級清單，用同一維度比較同類材料 | 分類與要點，並把例外、定義及來源放在相關項目旁 |
| 壓縮內容、聚焦重點 | 保留會改變理解或決策的資訊，合併重複說法，刪除次要細節 | 精簡重點，保留關鍵數值、單位、適用期間與例外條件 |
| 找出重複模式或可能的關聯 | 標出跨記錄重複的現象、例外與替代解釋，分開呈現觀察和推斷 | 每個候選模式附記錄依據、影響、例外與待驗證事項 |

同一件事被轉述多次時，按同一事件處理。引用原始筆記編號、日期或資料列以便回查。材料太少時，列出已見線索和缺少的比較材料。未計算的頻率維持定性，因果主張須有額外證據。

## 例子

使用者說「整理四則退款筆記，看看有沒有重複問題」。若兩則筆記都提到同一張訂單找不到入口，寫成「一張訂單出現入口難找的回報（筆記 1、2）」。如果另外兩則分別談到退款速度與金額，分別列出。入口問題可列為待驗證線索。
