# Junhao-Thinking-Toolkit

[繁體中文](README.md) · **简体中文** · [English](README.en.md) · [日本語](README.ja.md)

把零散的想法整理成可分析的问题，再用同一套 Agent Skill 理解概念、检验假设、比较方案或安排行动。工具箱包含 12 种核心方法，以及整理材料、假设检验、逐步引导和行动规划四个轻量入口。每次根据任务选择一种主要方法。

## 快速开始

1. 下载仓库，或使用 Git 克隆。

   ```sh
   git clone https://github.com/junhao-ye/Junhao-Thinking-Toolkit.git
   ```

2. 将整个 [`skills/junhao-thinking-toolkit`](skills/junhao-thinking-toolkit) 文件夹复制到 Agent 的技能目录。Codex 的用户技能目录可用 `~/.codex/skills/`。
3. 打开新对话，选择或点名 `junhao-thinking-toolkit`，提供目标、材料和希望得到的结果。

> 使用 junhao-thinking-toolkit 整理以下客服笔记。按主题分组，标出重复问题及其原始记录，最后列出最值得验证的线索。请用简体中文回答。

## 从哪里开始

| 你想完成的事 | 可以指定的方法 |
| --- | --- |
| 理清思路或找出真正的卡点 | 整理材料、苏格拉底式提问 |
| 理解概念、拆解案例或核实说法 | 双层解释、反向拆解、事实核查 |
| 找出方案的薄弱之处或其他解法 | 假设检验、专家会诊、第一性原理 |
| 比较选项、验证未知或排出时间表 | 双向钢人论证／多选项比较、最小可逆实验、行动规划 |

完整的方法索引、可复制的提示词、安装检查和常见问题见[简体中文使用手册](docs/user-guide.zh-CN.md)。
