# 做出決策

選項難以取捨時用「雙向鋼人」或多選項比較。關鍵未知可用小規模試驗釐清時，用「最小可逆實驗」。方向已定且需要安排工作時，用「行動規劃」。

## 雙向鋼人

1. 重述真正要做的選擇，包含目標、期限、限制與不可犧牲底線。
2. 分別為兩個方向建立最強版本，不攻擊弱化後的稻草人。
3. 對每個方向列出：
   - 最強理由；
   - 適用條件；
   - 最大收益；
   - 最大風險；
   - 在目前條件下最可能的結果；
   - 最難回答的反對意見。
4. 找出真正分歧、共同前提、最可能改變結論的變數與缺失資訊。
5. 若關鍵變數可由使用者補充，只問一個最有決策價值的問題。
6. 回答後給出明確建議、理由、適用條件、反轉判斷的訊號與下一步。

若選項超過兩個，用相同準則比較各選項的收益、代價、風險、可逆性與可能結果。準則依使用者目標與底線選擇。權衡取決於未定偏好時，給出條件式建議，指出哪項取捨會改變排序。

## 最小可逆實驗

1. 列出決策背後最多 3 個可驗證假設。
2. 選出最可能改變決策、且能被短期行為觀察的那一個。
3. 設計 7 天左右或使用者可接受週期內的實驗；若自然週期較長，明確說明不能壓縮的原因。
4. 實驗須寫清：
   - 具體行動；
   - 時間、金錢與人力投入；
   - 主要指標與資料收集方式；
   - 支持繼續的門檻；
   - 提醒停止或轉向的門檻；
   - 實驗結束能新增哪項資訊。
5. 最後給出 24 小時內可完成的第一個動作。

## 實驗品質檢查

- 只測一個主要假設，避免同時改太多變數。
- 優先觀察真實行為，不只收集口頭意向。
- 設定停止條件，避免沉沒成本擴張。
- 不把小樣本結果宣稱為普遍因果；把它視為更新決策的證據。
- 涉及健康、安全、法律、財務或他人權益時，不以自行試錯取代專業意見或必要同意。

## 行動規劃

1. 從已選方向提取可觀察的完成標準，列出達成目標所需的任務。
2. 依相依性與優先順序排列任務，為每一階段附時段或里程碑。有期限與資源資訊時據此排程。只有相對資訊時，用先後順序與相對時段，明列待確認的期限、資源或負責人。
3. 為最可能卡住的環節列出阻礙、應對方式與調整時機。
4. 交付「完成標準 → 任務與優先順序 → 時程與依賴 → 阻礙與應對 → 現在可做的第一步」。
