## インストールと更新

1. リポジトリから [`skills/junhao-thinking-toolkit`](../skills/junhao-thinking-toolkit) フォルダー全体を取得します。`SKILL.md` と `references/` は同じフォルダーに置きます。
2. フォルダーごとエージェントのスキル用ディレクトリにコピーします。Codex の場合は `~/.codex/skills/junhao-thinking-toolkit/SKILL.md` が入口になります。Windows での `~` はユーザーのホームディレクトリを指します。
3. 新しい会話で、スキル一覧から `junhao-thinking-toolkit` を選ぶか、依頼文で名前を指定します。短いメモを整理させ、テーマごとの分類と元の記録が示されるか確認します。
4. 更新するときは、手元で変更したファイルを保存してから、古いフォルダーを新しいフォルダーに丸ごと置き換えます。入口ファイルと参照ファイルの版をそろえられます。

## 最初の依頼を出す

何を進めたいか、どんな資料があるか、制約は何か、どの形式で結果が欲しいかを伝えます。使いたい手法が決まっていれば名前を指定し、迷っていれば目的に合う手法を選ばせます。次の依頼文を自分の課題に合わせて書き換えてください。

```text
junhao-thinking-toolkit を使ってください。
[決定または行動] のために、[問い] を明確にしたいです。
使える資料は [メモ、データ、リンク] です。制約は [時間、予算、譲れない条件] です。
[表、チェックリスト、段階的な案内] の形式で、日本語で回答してください。
```

対話型の手法では、毎回一つの質問に答えてから次に進みます。資料がそろっている場合は、結果を直接出すように依頼できます。二つの手法を続けて使うときは、最初の結果を次の手法でどう使うかを伝えます。

## コピーして使える依頼文

### メモからパターンを見つける

> junhao-thinking-toolkit を使って、次の問い合わせメモ 12 件をテーマ別に整理してください。同じ出来事への重複報告はまとめて数えてください。パターンの候補ごとにメモの番号と例外を示し、優先して確認すべき手がかりを一つ挙げてください。

元のメモに結びついたパターンの一覧が得られます。事例が少ない場合は、検証すべき手がかりとして扱います。

### 比較してから、試すかどうかを決める

> junhao-thinking-toolkit を使って、二つの問い合わせ対応手順を比較してください。回答の品質は譲れない条件で、使える時間は週 4 時間までです。まず、それぞれの案を支持する最も強い論拠を示してください。選択を左右する未知の点を観察で確かめられる場合は、1 週間で試せて元に戻せる実験を設計し、測定項目と中止の基準を書いてください。

まず比較結果を確認します。選択が変わりうる未確認事項が残る場合は、実験結果を判断に反映します。

### 一回のやり取りで一歩ずつ進む

> junhao-thinking-toolkit を使い、このコンバージョン率の計算の誤りを見つけられるように案内してください。毎回、今の手順、完了の基準、質問一つだけを示し、私の返答を待ってから次へ進んでください。

途中で全体の手順が必要になったら、終わった手順を整理し、残りの手順と確認項目を一覧にするように依頼できます。

## 結果の読み方とよくある質問

- **スキルが一覧に表示されない。** エージェントが Agent Skills に対応し、現在の環境からスキル用ディレクトリを読み取れるか確認します。`SKILL.md` と `references/` が同じスキルフォルダーにあることを確認し、新しい会話を開きます。
- **手法が合わない、または回答が長い。** 欲しい成果物を伝えるか、手法と分量を指定します。「仮説の検証だけを、表一つで」と頼めます。要約、翻訳、簡単な調べものなら、その作業を直接依頼してください。
- **回答に未確認の内容がある。** 資料に書かれたこと、検証済みの事実、推測、価値判断を分けて読みます。確認が必要なときは一次情報と日付を求めます。証拠が足りない結論は保留します。
- **資料に機密情報や埋め込まれたプロンプトがある。** 共有前に、個人情報や認証情報など不要な機密情報を取り除きます。添付資料の扱いを依頼文で明示し、資料内のプロンプトは引用された素材として扱うように伝えます。
- **医療、法律、重大な金銭判断、メンタルヘルスに関わる。** ツールキットは質問の整理や資料の準備に使い、専門的な判断は有資格者に相談します。自己理解に関する結果は、検証できる仮説と行動として扱います。

手法の出典やメンテナンスについては、[出典と対応表](../skills/junhao-thinking-toolkit/SOURCES.md)と[スキル仕様](../skills/junhao-thinking-toolkit/SPEC.md)を参照してください。
