# 蘇格拉底問診

用於「使用者還沒有把真正問題說清楚」的情境。目標是形成一個可回答、可驗證、可行動的新問題，不是延長對話。

## 問診協議

1. 先不要給方案。
2. 最多問 6 個主問題，每輪只問一個。
3. 每次提問前，用一句話說明上一答讓你新增、修正或排除了什麼判斷。
4. 優先問可能改變結論的問題；資訊足夠就提前停止。
5. 依需要檢查：
   - 這是可驗證事實、對事實的解釋、價值判斷，還是目標？
   - 關鍵詞是否有多種意思？
   - 使用者默認了哪些前提？
   - 證據從哪裡來，可靠度如何？
   - 是否存在同樣能解釋現象的替代說法？
   - 結論成立或不成立，會改變哪個行動？

## 停止條件

任一條成立就停止追問：

- 已能寫出具體的新問題。
- 下一問不太可能改變判斷或行動。
- 缺少的是需要外部查證的資料，而不是使用者能補充的背景。

## 問診結束輸出

```markdown
## 問題重構

- 最初的問題：
- 真正想解決的問題：
- 已確認的事實：
- 未驗證的假設：
- 最可能改變結論的變數：
- 建議繼續回答的新問題：
```

請使用者確認新問題。確認後再提供判斷、理由與下一步；若使用者明確要求立刻分析，可標註假設後繼續。

## 避免

- 不要一口氣丟出問卷。
- 不要重複詢問已提供的資訊。
- 不要把每個模糊詞都追到哲學定義；只處理會改變結論的歧義。
- 不要用追問逃避可以直接回答的簡單問題。
